# 言衡 · CET-SET6 口语模拟系统

一个可在本机浏览器运行的六级口语模拟系统：

- Part 1 自我介绍与问答、Part 2 个人陈述与 AI 多轮讨论、Part 3 深度问答均由 API 动态出题。
- Part 1 的两道 30 秒问答会从不同生活或校园类别中随机选题，并自动避开近期题目及过度重复的“空闲时间 / 周末安排”问法。
- 可分项训练，也可完成整套模拟。
- 每个 Part 开始前显示考试要求、流程和时限；录音倒计时归零后自动停止。
- 浏览器直接调用麦克风，录音在本地转为 16 kHz WAV 后交给 API。
- 每题生成转写、语音表现与语言表现诊断；全卷按 15 分量表汇总。
- 每题固定生成“你的作答优化版”和“标准答案”两份英文答案。除自我介绍外，两份答案均严格使用“观点 → 理由一 → 例子一 → 理由二 → 例子二 → 总结”模板，并提供一段可直接朗读的完整答案。
- DeepSeek API Key 仅保存在本地 Node 服务端，不发送到浏览器。

## 运行

要求 Node.js 20 或更高版本。

```powershell
cd D:\Doubao\cet6-speaking-simulator
npm install
Copy-Item .env.example .env
notepad .env
npm start
```

在 `.env` 中填写 `DEEPSEEK_API_KEY` 后，打开 `http://localhost:5176`。

如果暂时没有 API Key，可把 `DEMO_MODE=true`。演示模式能检查页面和录音流程，但不会转写或真实评分。

## 模型配置

可通过 `.env` 更换模型：

```env
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

文本出题、讨论与评分使用 `deepseek-flash`；录音通过 DeepSeek 官方 `/v1/tools/asr` 接口转写。账号若没有默认模型权限，请改成该账号实际可用的模型。

## 评分说明

全卷按 CET-SET6 的三个分析维度各 5 分评估：

1. 准确性和范围
2. 话语长短和连贯性
3. 灵活性和适切性

自 2023 年 5 月考次起，官方报告使用“优秀 / 良好 / 合格”三级能力描述。本系统将传统 15 分边界映射为：13.5–15 优秀、11–13.4 良好、8–10.9 合格、8 分以下未达合格。后者是训练提示，不是官方成绩报告。AI 评价不能替代正式考试的人工评分。

## 模拟时限

- Part 1：自我介绍 20 秒；两个问题各 30 秒。
- Part 2：准备 1 分钟；个人陈述 1 分 30 秒；三轮 AI 模拟讨论，总体控制在约 3 分钟内。
- Part 3：一个主题问答，45 秒。

## 字母评级

每道题根据五项分数的平均值给出字母评级；完整模拟根据 15 分总分折算后给出总体评级。评级包含 `A+ / A / A- / B+ / B / B- / C+ / C / C- / D+ / D / D-`。`C` 及以上判定为合格，`C-` 及以下判定为未合格。该字母评级是本系统的训练性细分评级。

## 隐私与成本

- 作答录音会上传到 DeepSeek ASR 进行转写，转写文本和本地声学指标会交给 DeepSeek 文本模型分析。
- 项目默认不把录音写入磁盘；刷新页面后浏览器内的本次结果会消失。
- 完整考试会产生多次音频与文本 API 调用，费用取决于录音时长和所选模型。

## 麦克风排查

- 必须通过 `http://localhost:5176` 打开，不要直接双击 `index.html`。
- 首页“测试麦克风”会进行约 2 秒的真实声音检测，不只是检查浏览器权限。
- 首页“选择麦克风”可以手动指定输入设备；系统默认排除 VB-Audio CABLE、Virtual、Stereo Mix 等虚拟输入，并优先选择笔记本的麦克风阵列。
- 正式录音时应看到音量条随说话跳动，并出现“已检测到你的声音”。
- 如果设备已连接但没有声音，请在 Windows“设置 → 系统 → 声音 → 输入”中选择正确的麦克风，并确认浏览器具有麦克风权限。
